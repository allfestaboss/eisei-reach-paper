## 2. 設計

### 2.1 地域を1つに固定して、15本実装する

対象は福岡県。固定は設計判断であり、代償を先に書く ──
**少なくとも1業種では、地域が結論を決めている。**
福岡の田植えは6月中〜下旬で、梅雨と完全に重なる。該当する窓の晴天率は 0.0〜5.5%。
**晴れている日は田植え前、田植え後は晴れない。**
ここで光学による水稲把握は難しいのではなく、成立しない。
別の地域に固定した研究は、同じ業種に別の壁を報告しただろう。

それでも固定するのは、代案のほうが悪いからである。
業種ごとに一番うまくいく地域で測れば、業種横断の比較は**地域選びを測っている**ことになる。
全国展開は「同じことを1,741回」ではなく「条件の違う測定を1,741通り」で、
コストの問題ではなく**未測定**の問題である。
参照統計が都道府県別である2業種（花粉・NO2）だけは全国で測った。

使ったのは無料・無認証の経路だけ ── Copernicus Sentinel-1 RTC / Sentinel-2 L2A / Sentinel-5P を
Microsoft Planetary Computer と Earth Search 経由で、Landsat Collection 2 Level-2、MODIS、
10m年次土地被覆、Copernicus DEM、NOAA の混合海面水温（ERDDAP）、ひまわり9号。
Planetary Computer は無認証の GET に短命の署名URLを返すので、パイプラインのどこにもアカウントは存在しない。
1つだけ開かなかった ── 夜間光である。無料の経路が見つからず、
夜間光を定石とする2業種は代替手法で実装し直し、その旨を明記してある。

### 2.2 参照解を公費調達に置く

自分を測る研究の問題は、被験者と試験官が同一人物であることに尽きる。
防御は、**答えを自分の手の届かない場所に置く**ことである。

調達ポータルは中央省庁の競争入札の落札実績を年度別 ZIP で配っている。
13年度（平成26〜令和8）で 312,584件、列は8つ ──
調達案件番号・案件名・契約日・契約金額・区分・機関コード・受注者名・法人番号。
衛星・リモートセンシングに絞り、通信と設備を落とし、解析・調査系だけ残すと332件。
**測定した9業種すべての参照解がここから出た。**

4つの罠を記録しておく。どれも時間か誤った主張の代償を払った。

1. **文字コード。** UTF-8 BOM付き・ヘッダ行なし。
   先頭4,000バイトから推定するとマルチバイト文字が割れて全候補が失敗し、「判定不能」になる。
2. **収録範囲。** これは**競争入札だけ**である。随意契約は入っておらず、自治体の発注も入っていない。
   国土地理院の令和7年度SAR随意契約4件（合計8,435万円）は、別に公表される随意契約結果書からしか取れない。
3. **キーワード。** 「衛星」で引くと衛星電話・衛星通信・気象衛星センターの空調点検が出てくる。
   逆に「航空レーザ」は「航空」と衝突し、実体の無い業種に46件の偽の会員を作った。
4. **機関コードは省庁を特定しない。** 8002010 という1つのコードに、
   法務省・国土交通省・環境省・林野庁が混在する。

**契約は要求水準を書いていない。** 書いてあるのは支払額だけである。
要求精度は製品仕様書か仕様書のほうにあり、両方読まないと採点規則が作れない。
採点を決めた例を2つ挙げる。国土数値情報（土地利用）の適合品質水準は
**「判読原図に対して誤率0%」**であり、環境省の藻場調査は商用50cm・8バンドで
全体精度 53.42〜85.91% を達成したと報告している。
前者は「正解が人の判断の中にある」と言っており、後者は無料手法と比べられる数値をくれる。

### 2.3 凍結の手順

測定を走らせる前に、次の4つを書いたファイルを置き、以後編集しない。

- **問い**と、それが §2.4 の枠組みのどのセルに属するか
- **参照解**（件名・発注機関・受注者・契約金額）
- 区間つきの**数値予測**
- 閾値として書いた**判定基準**と、同時に凍結する**対抗馬**（打ち倒すべき代替説明）

走らせた後に、その基準に対する判定を別ファイルに記録する。
予測ファイルが存在するのは、**当たった予測も監査できるようにするため**であり、
これは事前登録の通常の動機とは対称ではない。
第4節の台帳の2件は、予測がきれいに当たりすぎたという理由だけで捕まった。

**最も結果を変えたのは対抗馬である。** NO2 の業種では、相関の目標値ではなく
「生の相関は高く出るが、それでも人口に負ける」を基準として凍結した。
測定された生の相関は 0.910 で、通常の読み方なら成功である。
**凍結した基準だけが、これを未到達として記録させた。**

### 2.4 4つの観測量と、2つの標本

衛星が測っているのは4つである ── **強度・波長・偏波・位相**。
平たく言えば、明るさ、色と温度、電波の跳ね返り、気体の吸収。
空間と時間は量ではなく、それらの**標本**である。合わせて6セルになり、
技術の壁7種のうち4つがそこにきれいに落ちる ── 波長の選択、位相の有無、空間標本、時間標本。

この枠組みが役に立ったのは、**自分の仕事について何かを捕まえたから**である。
**最初の15本は2セルしか使っていなかった。** うち3本は解析準備済みSARの `vv` しか読んでおらず、
`vh` は**同じ無料資産の中に**未読のまま入っていた。
**入手経路が黙って観測量を決めていた** ── 解析準備済みプロダクトは振幅を残して位相を既に捨てており、
単一ルック複素（SLC）は振幅も位相も偏波も残すが処理が重い。**どちらも無料である。**
6セルのうち、金で動くのは**空間標本の1つだけ**だった。

そこで偏波が効くかを、対抗馬の階段（光学のみ／VV単独／VV+VH）を凍結して測った。
光学が強い太陽光（AUC 0.951）では、偏波の上積みは **-0.003**。
光学が効かない建物（NDBI 0.607 / NDVI 0.618）では、VH単独が全単独特徴で最高の 0.734 で、
偏波の上積みは VV単独比で +0.027、光学+VV比で +0.041。
**判定は「効くが、足りない」** ── 天井は AUC 0.78 程度で、改善は光学が既に失敗した場所にしか現れない。
Sentinel-1 IW はデュアル偏波でフル偏波ではないので、これは無料デュアル偏波についての言明であって、
ポラリメトリ一般についての言明ではない。
